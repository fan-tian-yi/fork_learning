# fork_learning

Git 分支与合并练习仓库。

- 远端：https://github.com/fan-tian-yi/fork_learning
- 用途：配合 11 章学习路线，练分支、合并、冲突、PR
- 约定：这个仓库可以随便搞坏。`git reset --hard` 和 `git reflog` 是你的安全网

## 目录

```
src/main/java/com/demo/          一个假的订单模块，用来制造真实冲突
  OrderService.java              下单 / 计价逻辑
  config/AppConfig.java          配置
docs/PRACTICE.md                 各章练习口令
```
